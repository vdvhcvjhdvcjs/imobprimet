# Tarciso Prime — publicação

Esta é a versão atual do site oficial. Para publicar no Worker `imobprimet`:

1. Use o arquivo `dist/index.html` ou o pacote atualizado.
2. No Cloudflare, abra **Workers & Pages → imobprimet → New deployment**.
3. Escolha **Upload static assets**.
4. Envie uma pasta que contenha `index.html` na raiz.
5. Clique em **Deploy** e confirme o novo deployment.

Não publique arquivos obtidos de uma saída de terminal ou de uma visualização truncada. O arquivo correto começa diretamente com `<!doctype html>`.
